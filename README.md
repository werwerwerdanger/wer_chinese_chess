# Chinese Chess (中国象棋) — 计算机问题求解课程设计

成都理工大学《计算机问题求解课程设计》题目12：亚洲象棋。

## 项目目标

实现一个带 AI 对弈的中国象棋网页程序，满足课程要求：

- 人机 / 人人对弈，主菜单，界面友好
- 完整走子规则与合法性判定（将军、送将、将帅照面）
- AI 引擎：Alpha-Beta 剪枝 + 迭代加深 + 评估函数
- 报告：七章结构（博弈发展 / 棋类详解 / 算法模块 / UI 设计 / 项目实现 / 结论展望 / 分工）

## 技术选型

| 模块 | 方案 | 说明 |
|------|------|------|
| 前端 UI | HTML5 Canvas + 原生 JS（或 TypeScript） | 单页应用，无框架依赖，演示零配置 |
| 引擎 | JS/TS 与前端同语言（满足"组内统一语言"） | 后续如性能不足再考虑 C++ → WASM |
| 构建 | Vite（可选，初期直接静态文件） | 打开 index.html 即可运行 |

## 目录结构

```
chinese-chess/
├── engine/        # AI 引擎：走子生成、搜索、评估
│   ├── board.js    # 棋盘表示与走子生成
│   ├── search.js   # Alpha-Beta + 迭代加深 + 置换表
│   └── eval.js     # 评估函数
├── web/            # 前端界面
│   ├── index.html
│   ├── ui.js       # 渲染与交互
│   └── assets/     # 棋子图片等素材
├── docs/           # 报告素材、规则文档、参考资料
└── README.md
```

## 里程碑

1. [ ] M1 棋盘表示 + 走子生成 + 合法性判定（人对人可下）
2. [ ] M2 评估函数 + 2 层 Alpha-Beta（能赢随机走子）
3. [ ] M3 迭代加深 + 置换表 + 历史启发（对战官方示范程序）
4. [ ] M4 UI 打磨：主菜单、悔棋、提示、难度选择
5. [ ] M5 报告撰写（与开发并行）

## 备注

- 课程评分：平时 10% + 比赛 30% + 答辩 40% + 报告 20%
- 同一题班内多组可选，代码相同均零分 —— 注意代码自主性
