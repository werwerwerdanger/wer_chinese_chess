### 技术选型讨论（>>报告素材："算法分析与功能分析"章节）

**选型过程**：调研了 2026-08 象棋引擎天梯（皮卡鱼 4002 断层第一/开源，旋风 3986/闭源），确定自研路线：
- 直接套壳 Pikafish = 答辩判抄袭（40% 归零），只可作陪练对手
- Fork XQWLight 改参数 = "自己开发"不成立，高危
- **选定：读开源学算法思想 + 全部自己实现**（参考 XQWLight 的 PST 结构与 nnue-pytorch 的特征设计，代码零拷贝）

**M3 计划（传统评估 + αβ）**：
1. eval.ts — 子力价值 + 位置价值表（PST）+ 机动性
2. search.ts — αβ 剪枝 + 迭代加深 + 置换表（复用 M1 Zobrist）+ 历史启发 + 静态搜索（防水平线效应）
3. 验收：胜随机走子 → 对固定深度 XQWLight 有来有回 → 自对弈棋力曲线

**M4 计划（NNUE 蒸馏，选做升级）**：
- Pikafish 当教师引擎批量评估局面（50-100 万样本）
- PyTorch 训小网络（输入 90×15 稀疏特征 → 隐层32 → 输出1分数，INT8 量化 <1MB）
- 权重导出 JSON → TS 引擎 eval 前向推理（纯矩阵乘 ~100 行）
- 硬件评估：本机 RTX 5070 Laptop 8GB + 16GB RAM，训 150K 参数小网络绰绰有余
- 预期棋力 2200-2500
