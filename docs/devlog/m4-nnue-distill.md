# M4 NNUE 蒸馏 开发日志（规划）

## 2026-09-12 21:47 规划（未动工）

### 路线（与用户讨论确定）
"找一个能激活的模型自己训练"——不是接 LLM，而是**自训 NNUE 评估网络**替换手写评估：

```
第1步 教师数据：Pikafish 批量评估局面 → (局面, 分数) 对，50-100 万样本
      （自对弈采样 + 残局库采样，CPU 跑即可）
第2步 学生网络：90格×15子 one-hot 稀疏特征(≈1350维) → 隐层32 → 输出1
      PyTorch 定义，参数量 ~150K
第3步 训练：5070 8GB，MSE 拟合教师分数，单轮半小时级
第4步 导出：INT8 量化 → JSON 权重 <1MB
第5步 接入：TS eval.ts 写前向推理（纯矩阵乘），LocalEngineAdapter 挂载
```
