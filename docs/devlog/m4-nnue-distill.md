
## 2026-09-12 22:45 硬件升级：自博弈路线可行性提升

用户补充训练硬件：**RTX 4080 48GB（改装版）**，可长期跑自博弈。

### 对 M4 计划的影响
- 原 A 路线（Pikafish 蒸馏）不变，仍是保底
- **新增 B 路线（AlphaZero 式自博弈）升级为可选主攻**：
  - 48G 显存：policy/value 双头网络（ResNet 5-10 blocks）+ MCTS 批量推理（batch 256+）都能放下
  - 自博弈数据生成：GPU 推理 + CPU 并行对局（self-play worker xN）
  - 4080 的 FP16/TF32 吞吐对小网络训练完全够用
- 现实预期管理：课程时间内（约一学期）从零自博弈到超过自研 αβ 引擎（~2000 分）是合理目标；
  追平 Pikafish 不现实（那是几千卡时级自博弈的产物），报告里如实写
- 混合方案（最务实）：**自博弈 + Pikafish 蒸馏双数据源**——自博弈提供探索性局面，Pikafish 标注提供高质量分数，收敛更快
